### Projects
- [toluca-recomp](https://github.com/Pobega/toluca-recomp) - Clean-room static recompiler and native Linux / OpenGL ES 3.0 runtime for *Silent Hill 2* (PC) on Linux desktop and PortMaster ARM64 handhelds
- [gnome-shell-indicator-mullvad](https://github.com/Pobega/gnome-shell-extension-mullvad-indicator) - Indicator icon that displays MullvadVPN connection status (install at [extensions.gnome.org](https://extensions.gnome.org/extension/3560/mullvad-indicator/))
- [com.fightcade.Fightcade](https://github.com/flathub/com.fightcade.Fightcade) - Flatpak for [Fightcade](https://www.fightcade.com/), a service to play arcade games online (install at [Flathub.org](https://flathub.org/apps/details/com.fightcade.Fightcade))

### NextUI Handheld Ecosystem
- [nextui-parallel-n64-pak](https://github.com/Pobega/nextui-parallel-n64-pak) - Nintendo 64 (ParaLLEl N64) GLES3 libretro emulator pak for NextUI (`tg5040`, `tg5050`, `h700`)
- [nextui-flycastrophe-pak](https://github.com/Pobega/nextui-flycastrophe-pak) - Sega Dreamcast ([Flycastrophe](https://github.com/Helaas/Flycastrophe)) GLES libretro emulator pak for NextUI
- [nextui-cheevoscraper-pak](https://github.com/Pobega/nextui-cheevoscraper-pak) - NextUI Tool Pak that pre-downloads RetroAchievements caches and badges for offline play
- [NextUI-v90s](https://github.com/Pobega/NextUI-v90s) & [BaseOS-v90s](https://github.com/Pobega/BaseOS-v90s) - NextUI and BaseOS ports for the Powkiddy V90S (Allwinner A133P)

### PortMaster Ports
- [Sin & Punishment](https://github.com/Pobega/snprecomp-portmaster) - OpenGL ES 3.0 PortMaster port of the Nintendo 64 *Sin & Punishment* static recompilation
- [Trouble Makers](https://github.com/Pobega/trouble-makers-portmaster) - OpenGL ES 3.0 PortMaster port of *Trouble Makers* (*Mischief Makers* N64 static recompilation)
- [Rez](https://github.com/Pobega/rez-portmaster) - OpenGL ES 3.0 PortMaster port of the Sega Dreamcast *Rez* static recompilation (available on [PortMaster](https://portmaster.games/))
- [Silent Hill 2 (toluca-recomp)](https://github.com/Pobega/toluca-recomp) - Clean-room static recompiler and GLES3 runtime targeting 1 GB RAM ARM64 PortMaster handhelds
